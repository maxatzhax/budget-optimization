# Data

| Folder | Contents | In git? |
|---|---|---|
| `sample/` | Synthetic dataset of an industrial enterprise (20 budget items, 7 departments), generated by `scripts/generate_synthetic_data.py --seed 42` | yes |
| `raw/` | Real budget data of the partner enterprise | **no** — confidential, see below |
| `processed/` | Cleaned data derived from `raw/` | **no** |

## Sample data format

`sample/budget_items.csv`

| Column | Type | Description |
|---|---|---|
| `item_id` | str | unique id |
| `item_name` | str | budget item |
| `department` | str | must exist in `departments.csv` |
| `min_amount`, `max_amount` | float | allocation bounds, million KZT |
| `return_recession`, `return_stable`, `return_growth` | float | effect per 1 unit spent under each scenario |
| `mandatory` | bool | if true, the item is fixed at `min_amount` |

`sample/departments.csv` — `department`, `min_share`, `max_share` (share of the allocated budget, 0–1).

All numbers in `sample/` are illustrative and do not describe any real company.

## Real data

The real enterprise data used in the thesis are confidential and are **not**
published. To reproduce the analysis on your own data, put two CSV files with
the columns above into `data/raw/` and run:

```bash
python scripts/run_experiment.py --items data/raw/budget_items.csv --departments data/raw/departments.csv --budget <B>
```
